Private cloud sync

Connect a free Supabase project to sync sightings and photos between devices. Your project URL and publishable key are saved in this browser only. Use the same BirdDex login on your phone and laptop.

Not connected. Configure Supabase below to enable syncing.

Setup requirements
In Supabase, create a table named birddex_data with columns user_id (uuid, primary key, references auth.users), payload (jsonb), and updated_at (timestamptz). Enable row-level security and add the SQL policies from the setup guide. Create a private Storage bucket named bird-photos and add storage policies allowing authenticated users to access only objects inside their own user-id folder. Never use a service-role or secret key in this page.
